## Contrast (WCAG AA: 4.5:1 body, 3:1 large text/UI)

| Pair                         | Ratio   | Rule                                 |
| ---------------------------- | ------- | ------------------------------------ |
| Ink text on Cream            | 14.76:1 | ✅ Body & headings                   |
| Cream text on Forest         | 7.02:1  | ✅ Inverse sections, footer          |
| Ink text on Honey            | 8.91:1  | ✅ Primary buttons, accent badges    |
| Honey text on Forest         | 4.24:1  | ✅ Eyebrows/accents on Forest only   |
| Forest text on Cream         | 7.02:1  | ✅ Links, brand headings             |
| Coral/700 text on Cream      | 4.71:1  | ✅ Error messages only (short)       |
| Honey text on Cream          | 1.66:1  | ⛔ Never use honey for text on light |
| Coral/500 body text on Cream | 2.76:1  | ⛔ Coral is not a body-text color    |
