# Typography

**Fraunces 600** (display/headings) + **Inter 400/500/600** (body/labels), self-hosted WOFF2 (OFL) shipped inside the
package. 18 text styles mirror the Figma text styles. Use them through `<Text variant="…">` — never set font sizes
by hand.

Each style exposes five tokens: `--text-<style>` (size), `-line-height`, `-tracking`, `-weight`, `-family`.

## Responsive roles

Roles change style with the **page container** width (not the viewport), exactly like Figma breakpoint variants.
