# Spacing

Base-4 scale. Section padding: 96 desktop / 64 mobile. Card padding 24–32, form gap 20, grid gap 16 / 24 / 32.
`<Stack gap={…}>` only accepts steps of this scale.

<SpacingScale />

# Radius & border

Buttons, badges, link buttons = **full** · inputs = **md** · cards = **lg** · pricing/form cards & illustrations = **xl**.

<RadiusScale />

# Sizes, layers & motion

Fixed dimensions (icons, controls, illustration heights, measures), z-index layers and motion values. **If you need a
number that is not here, the design is missing a decision** — add it to `src/tokens/scales.ts` first.
