# Changelog

The package follows [Semantic Versioning](https://semver.org). Every version merged to `main` with a number higher
than the one on npm is published automatically. See `CHANGELOG.md` in the repository for the full history.

| ------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1.1.0   | 2026-10-20 | Site v1.1 support: `honey/300` for accent text on Forest (4.75:1, AA), `closing` text role, `facebook` icon, `ConceptSiteArt`, `WorkCard` `badge` prop, `Prose` molecule, phone illustration without stars, web links open in a new tab. |
| 1.0.0   | 2026-10-19 | First release: tokens (generated CSS + typed JS), 19 atoms/layout primitives, 14 molecules, 13 organisms, PageShell template, Storybook docs. Ported from the Wren Pages Figma/Claude Design v1.0.                                       |
